# SafeVault — แอปจัดเก็บรหัสผ่านส่วนตัว (Android)

เก็บข้อมูลในเครื่องเท่านั้น ไม่มีสิทธิ์อินเทอร์เน็ต ไม่มี Analytics / Crash reporting
ภาษาไทยเป็นค่าเริ่มต้น (ข้อความทั้งหมดอยู่ใน `app/src/main/kotlin/app/safevault/ui/Strings.kt`)

> **สถานะ:** ยังไม่ผ่านการตรวจสอบความปลอดภัยจากผู้เชี่ยวชาญอิสระ ดูข้อจำกัดและสิ่งที่ยังไม่ได้ทดสอบใน `SECURITY_REPORT.md` ก่อนใช้กับรหัสผ่านจริง

## โครงสร้าง
- `crypto-core/` โมดูล Kotlin/JVM ล้วน: Argon2id, AES-256-GCM, การห่อกุญแจ, รูปแบบไฟล์สำรอง (เทสต์รันเร็วบน JVM)
- `app/` แอป Android: Room, Compose + Material 3, Keystore, BiometricPrompt, หน้าจอทั้งหมด
- `.github/workflows/` `ci.yml` (เทสต์ + debug APK), `release.yml` (APK เซ็นชื่อ), `instrumented.yml` (เทสต์บน emulator, รันเอง)

## Build
**GitHub Actions (แนะนำ):** push ขึ้น GitHub → แท็บ Actions → workflow `CI` → ดาวน์โหลด artifact `SafeVault-debug-apk` และ `test-reports`

**Android Studio:** เปิดโฟลเดอร์โปรเจกต์นี้ (JDK 17) แล้ว Sync
ยังไม่มี Gradle wrapper ในชุดนี้ ให้รัน `gradle wrapper --gradle-version 8.10.2` หนึ่งครั้ง หรือให้ Android Studio จัดการให้
คำสั่ง: `gradle :crypto-core:test :app:testDebugUnitTest :app:assembleDebug`
APK อยู่ที่ `app/build/outputs/apk/debug/`

## APK เซ็นชื่อ (release)
```
keytool -genkeypair -v -keystore release.jks -alias safevault -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 release.jks     # ค่านี้ใส่เป็น secret
```
ตั้ง GitHub Secrets: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` แล้วรัน workflow `Release APK (signed)`
เก็บ `release.jks` และรหัสไว้ที่ปลอดภัย (ห้าม commit) หากหายจะอัปเดตแอปเดิมไม่ได้

## ติดตั้งบนโทรศัพท์
1. คัดลอกไฟล์ `.apk` ไปที่เครื่อง → เปิดไฟล์ → อนุญาต "ติดตั้งแอปจากแหล่งที่ไม่รู้จัก" ให้แอปที่ใช้เปิดไฟล์
2. หรือใช้ `adb install app-debug.apk`

## รายการทดสอบด้วยมือบนเครื่องจริง
1. **ตั้งรหัสหลัก:** รหัสสั้น/เดาง่าย (เช่น `Password123!`) ต้องกดสร้างไม่ได้ วลียาว ๆ ต้องผ่าน
2. **ปลดล็อก:** รหัสผิดต้องแจ้งเตือน รหัสถูกเข้าได้ ปิดแอปแล้วเปิดใหม่ต้องถูกล็อก
3. **รายการ:** เพิ่ม/แก้ไข/ลบ (ต้องมีกล่องยืนยันก่อนลบ) ค้นหาภาษาไทยและอังกฤษ นับจำนวนตามหมวด
4. **รหัสผ่าน:** หน้ารายการต้องไม่แสดงรหัส หน้ารายละเอียดซ่อนเป็นค่าเริ่มต้น กด "แสดง" ต้องมีกล่องยืนยัน และซ่อนเองใน 15 วินาที
5. **คัดลอก:** คัดลอกรหัสแล้ววางที่อื่น รอครบเวลาที่ตั้ง คลิปบอร์ดต้องถูกล้าง ทดสอบทั้งตอนแอปอยู่หน้าจอและตอนออกจากแอป
6. **สร้างรหัส:** ปรับความยาว/ชนิดตัวอักษร ต้องได้ตรงตามที่เลือก
7. **รหัสซ้ำ/อ่อน:** เพิ่มรหัสเดียวกันสองรายการ และรหัส `123456` หน้าแรกต้องขึ้นคำเตือน
8. **ภาพหน้าจอ:** ถ่ายภาพหน้าจอต้องไม่ได้ และหน้า Recent apps ต้องเป็นหน้าว่าง
9. **ล็อกอัตโนมัติ:** ตั้ง 15 วินาที ปล่อยทิ้งไว้ต้องล็อก ลอง "ล็อกทันที"/"ล็อกตามเวลา" ตอนออกจากแอป และดับหน้าจอ
10. **ลายนิ้วมือ:** เปิดใช้ในตั้งค่า → ล็อก → ปลดล็อกด้วยนิ้ว จากนั้นเพิ่มลายนิ้วมือใหม่ในระบบ ต้องถูกปิดและกลับมาใช้รหัสหลัก
11. **เปลี่ยนรหัสหลัก:** ข้อมูลเดิมต้องยังอ่านได้ รหัสเก่าใช้ไม่ได้
12. **สำรอง/กู้คืน:** ส่งออกไฟล์ → ลบข้อมูลทั้งหมด → ตั้งรหัสหลักใหม่ → นำเข้า ต้องได้ข้อมูลครบ ลองรหัสผ่านไฟล์ผิด และไฟล์ที่ถูกแก้ไขด้วย hex editor ต้องถูกปฏิเสธ
13. **สิทธิ์:** ดู App info → Permissions ต้องไม่มี Internet / Network
14. **Log:** `adb logcat | grep -i "<รหัสผ่านที่ใช้ทดสอบ>"` ต้องไม่พบ
15. **ล้างข้อมูล:** ตัวเลือก "ลบข้อมูลทั้งหมด" ต้องให้พิมพ์ข้อความยืนยัน

## เทสต์อัตโนมัติ
- `crypto-core` (JVM): การเข้ารหัส/ถอดรหัส, การแก้ไขข้อมูล, รหัสผิด, เปลี่ยนรหัสหลัก, ไฟล์สำรอง, nonce/salt/key, ไม่มี log
- `app` (Robolectric + Room จริง): repository, การแก้ไข/สลับแถวในฐานข้อมูล, rollback ของ transaction, สำรอง/กู้คืน, นโยบายล็อก, ไม่มีข้อมูลลับใน log/ไฟล์ฐานข้อมูล, manifest ไม่มี INTERNET
- `app/src/androidTest` (ต้องใช้ emulator/เครื่องจริง): Android Keystore จริง — รันผ่าน workflow `Instrumented tests`
